## [0.1.0] - 2026-04-15

### Added

- The Himalayan Marmot website for Ladakh motorcycle tours, built with React, TypeScript and Vite.
- A chatbot for visitors' questions, using the Gemini API, and route maps with elevation drawn as SVG.
- This is the first tagged version. It describes the project as it was on 2026-04-15, before versions were tracked; the history before it is not rewritten.
